# Mid-Term Reflection

Selama mempelajari Software Development dari Minggu 1 sampai Minggu 7, materi yang paling sulit bagi saya adalah Branching, Merging, dan Resolusi Konflik pada Git.

Pada awalnya saya mengalami kesulitan memahami hubungan antara branch utama dan branch fitur. Saya juga sering bingung saat terjadi merge conflict karena belum memahami cara Git menggabungkan perubahan dari dua branch yang berbeda.

Untuk mengatasi hal tersebut, saya berlatih menggunakan perintah Git secara langsung, seperti git branch, git checkout, git merge, dan git log. Saya juga mencoba membuat simulasi conflict secara mandiri sehingga lebih memahami cara kerja Git dalam pengelolaan versi.

Selain itu, saya mempelajari konsep MVC dan dokumentasi API Contract. Materi tersebut membantu saya memahami pentingnya struktur proyek dan komunikasi antara Backend Developer dan Frontend Developer dalam pengembangan perangkat lunak.

Melalui pembelajaran ini, saya menjadi lebih memahami pentingnya version control, kolaborasi tim, dan dokumentasi dalam proses pengembangan perangkat lunak.
